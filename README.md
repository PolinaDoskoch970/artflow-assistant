# ArtFlow Assistant 🎨

Цифровая мастерская для художников - инструмент для систематизации творческого процесса.

## Функционал:
- Блокнот идей
- Генератор вдохновения
- Организация проектов

## Технологии:
- HTML5, CSS3, JavaScript

## 📌 Текущая версия: 0.7

### Что уже работает:
✅ **Версия 0.1: База**
- HTML страница с кнопкой
- CSS стили
- Проверка JavaScript

✅ **Версия 0.2: Форма для идей**
- Поле для ввода идей
- Кнопка "Добавить идею"
- Счетчик идей
- Работает по нажатию Enter
### Версия 0.2.1 (Сохранение идей)
✅ **Добавлено:**
- Сохранение идей в localStorage браузера
- Идеи сохраняются между перезагрузками страницы
- Идеи сохраняются после закрытия браузера
### Версия 0.2.2 (Блокнот идей - улучшение)
✅ **Добавлено:**
- Кнопка удаления для каждой идеи 🗑️
- Функция удаления с подтверждением через UI
- Сохранение изменений в localStorage
- Улучшенные стили для карточек идей

✅ **Версия 0.3: Цветовая лаборатория**
- Выбор цвета через палитру или HEX код
- Добавление цветов в палитру
- Просмотр сохраненной палитры
- Навигация между разделами

✅ **Версия 0.4: Навигация и интерфейс**
- Переключение между разделами "Идеи", "Цвета", "Проекты"
- Активные состояния кнопок навигации
- Плавные переходы между секциями
- Улучшенная структура приложения

✅ **Версия 0.5: Трекер проектов (прогресс-трекер)**
- Добавление проектов с этапами (Эскиз → Цвета → Детали → Фон → Освещение)
- Визуальный прогресс-бар (% выполнения)
- Отметка этапов выполненными (кнопка ✓)
- Переход к следующему этапу (кнопка →)
- Удаление проектов (кнопка ✗)
- Сохранение в localStorage

✅ **Версия 0.6: Генератор идей (конструктор)**
- Многокомпонентная генерация: жанр, сюжет, техника, цветовая гамма, настроение
- Кнопка "Сгенерировать идею" (случайная комбинация)
- Кнопка "Сохранить в блокнот" (добавляет идею в раздел Идеи с разделителем ;)
- Автоматическое обновление списка идей при сохранении

✅ **Версия 0.7: Интеграция блокнота и трекера**
- В блокноте идей добавлена кнопка 📋 для переноса идеи в трекер проектов
- При переносе создаётся новый проект с этапами (Эскиз → Цветовая основа → Детализация → Фон → Освещение)
- Трекер проектов обновляется автоматически (без перезагрузки страницы)
- Сохраняется активная вкладка при обновлении страницы

## 📁 Файлы
- `index.html` - главная страница
- `style.css` - стили
- `app.js` - логика
- `colors.js` - логика цветов
- `projects.js` - логика трекера проектов
